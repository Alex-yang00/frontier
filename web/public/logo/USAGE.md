# Frontier Logo Package

## Files
- `frontier-mark.svg` — icon only, light backgrounds (sage green #3f7d4f)
- `frontier-mark-on-dark.svg` — icon only, dark backgrounds (neon green #4ade80)
- `frontier-lockup-light.svg` — icon + "FRONTIER" wordmark, light backgrounds
- `frontier-lockup-dark.svg` — icon + "FRONTIER" wordmark, dark backgrounds
- `favicon-16.png`, `favicon-32.png`, `favicon-180.png` (apple-touch-icon), `favicon-512.png` (app icon / PWA)
- `social-share-en.png` — 1200×630 Open Graph image

## Colors
- Light mode mark: `#3f7d4f` (sage green)
- Dark mode mark: `#4ade80` (neon green)
- Wordmark text: `#1a1917` (light bg) / `#f4f4f5` (dark bg)
- Font: JetBrains Mono, 500 weight, uppercase, tight letter-spacing (-0.3px at 22px)

## Usage rules
- Minimum size: icon should not render below 20px — below that, the triangle detail gets muddy; use the plain favicon PNGs at small sizes instead of scaling the SVG mark.
- Clear space: keep at least half the icon's width as empty margin on all sides.
- Don't recolor the mark outside the two approved greens; don't add a background shape behind the lockup version (the icon and wordmark stand on their own).
- Topbar usage: lockup version, ~24–28px icon height.
- Favicon/app icon: mark-only version, transparent background.
