# Frontier 首页重新设计 — 交接说明

配合 `Frontier Home Redesign - Final.dc.html`（视觉稿）给 coding agent 参考。

## 1. 排版与内容长度规则

| 元素 | 字号(桌面) | 字重/字体 | 内容长度建议 | 超长处理 |
|---|---|---|---|---|
| Lead 标题 (#01) | 27px / Newsreader | 400 | 中文 18–28 字 / 英文 8–14 词 | 超过 2 行截断，末尾省略号 |
| Lead 摘要 | 15.5px / Inter | 400 | 中文 40–70 字 / 英文 20–35 词，1–2 句 | 最多 2 行，超出截断 |
| Standard 标题 (#02-03) | 19px / Newsreader | 400 | 同 Lead，略短更好 | 最多 2 行 |
| Standard 摘要 | 14.5px / Inter | 400 | 中文 25–45 字，1 句话讲清"是什么" | 最多 1 行 |
| More Today 标题 | 15px / Inter | 500 | 中文 ≤22 字 | 单行截断，不换行 |
| More Today 摘要 | 13px / Inter | 400 | 中文 ≤35 字，1 句 | 单行截断 |
| AI 今日摘要 | 16px / Newsreader | 400 | 中文 60–100 字，2–3 句，覆盖当天 2-3 条最重要的事 | 无截断上限，但超过约120字要考虑分段 |
| 元数据行 (来源·日期·标签) | 11.5–12px / JetBrains Mono | 400 | 固定格式：`来源 · 日期`，标签 ≤1个中文词/英文词 | — |
| Tag/topic 标题 (#tag页) | 30px / Newsreader | 400 | 标签本身，通常英文 1 词 | — |

**关键原则**：标题永远用原文/编译后的完整句子，不做营销式改写；摘要是"为什么值得看"，不是标题的同义重复。字号已经是分层的视觉权重（Lead > Standard > More Today），内容长度要服务这个权重——不能让 More Today 的摘要比 Lead 还长。

## 2. 交互说明

**列表页（首页/分区页/标签页）**
- 整行（编号+标题+摘要+元数据）可点击，非仅标题；hover 态标题变为下划线或轻微加深。
- 点击 → 原地从右侧滑出详情面板（桌面 560px 宽），不跳转页面、不丢失首页滚动位置。
- 视频行缩略图有独立播放态提示（▶图标），点击缩略图或标题行为一致，都打开详情面板。
- 标签（`#inference`）是独立可点击元素，点击跳转 `/tag/{slug}`，需要阻止事件冒泡（不触发打开详情面板）。
- 分区 tab（Technology/Capital/…）、日期条中的某一天：点击刷新当前列表内容，不跳转新页面（前端路由/query 参数即可）。

**详情面板**
- 关闭方式三种都要支持：点击右上 ✕、点击面板外遮罩区域、按 Esc。
- 键盘 `J`/`K`（或 `↓`/`↑`）切换上一条/下一条，面板内容原地更新，滚动位置重置到顶部。
- 文章类型：底部主按钮"Read on {来源}"跳转原文（新标签页打开）。
- 视频类型：面板顶部是内嵌播放器（16:9），不是缩略图；主按钮"Watch on YouTube"。
- "Coverage — 综合 N 个来源"列表里每条来源本身也可点击跳转对应原文。

**移动端**
- 详情从底部滑出（bottom sheet），非右侧面板；支持下滑手势关闭 + 顶部拖拽把手。
- J/K 快捷键在移动端不适用，改为面板内左右滑动切换上/下一条（或不做，先只支持关闭）。

**语言切换**
- 地球图标 + 当前语言文字，点击展开语言列表（当前仅中文/EN，为未来扩展保留列表形式而非简单toggle）。

## 3. 空态 / 加载态 / 异常态

| 场景 | 处理方式 |
|---|---|
| 某天/某分区无内容 | 用同宽度的空状态提示替代列表区，例如"这一天暂无收录内容"，不要留白 |
| 搜索无结果 | 提示 + 建议清除筛选条件 |
| AI 摘要生成失败/延迟 | 摘要卡片区域显示"摘要生成中…"骨架屏，而非隐藏整块 |
| 页面首次加载 | 列表用骨架屏（灰块占位，模拟标题+摘要+元数据三行），不用 spinner |
| 详情面板内容加载中 | 面板结构先出现（header/footer固定），中间内容区骨架屏 |

## 4. 响应式断点

- **≥1024px**：桌面布局，详情为右侧滑出面板（560px）。
- **768–1023px（平板/窄桌面）**：主内容区域宽度收窄，详情面板改为居中弹层（modal），宽度 min(90vw, 640px)，不再贴右边——避免面板挤压主列表到不可读宽度。
- **<768px**：移动端布局，详情为底部滑出（bottom sheet，78vh高）。
- 归档页的月热力图在 <768px 时横向可滚动，不缩小格子尺寸（保持可点击面积）。

## 5. 多来源标记（"×3 sources"）

前端只负责展示这个数字和展开列表，判定逻辑（同一事件的多条来源如何去重合并）由后端/内容管道决定。前端需要的数据结构最少包含：`sourceCount`、`sources: [{name, url, publishedAt}]`。数字为 1 时不显示该标记（避免"×1 source"这种无意义信息）。

## 6. 暂缓事项

- 深色模式：本轮未设计，需要单独决定是否要做。
- 用户系统/未读边界：已在本轮明确不做，相关设计已移除。
